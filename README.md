只有LOF基金（上市型开放式基金） 符合：场外申购、场内交易、有溢价。
 
一、核心类型：LOF基金（唯一答案）
 
- 双重交易：场外按净值申赎；场内按市价买卖（有溢价/折价） 
​
- 溢价来源：场内供需 > 净值 → 溢价；常见于QDII-LOF、商品LOF、热门指数LOF
​
- 关键前提：只支持场外申购、不支持场内申购（场内只能买卖） 

排除说明
 
- ETF：只能场内买卖/场内申赎（大额）
​
- ETF联接基金：只能场外申赎，无溢价 
​
- 普通开放式基金：只能场外申赎，无溢价
